      A record of
      every action.
      Keep an append-only, hash-linked local audit. Export its history and check it against an independently retained trusted tip.
      
          
      06 / Confirmation
      Change the request.
      Review it again.
      Confirmation belongs to the current review. Editing or cancelling invalidates it; export checks the policy and payment again.

      Quick start
      Python 3.9+
      
        
      From your local repository checkout:
      
        
      python3 scripts/policy_gatekeeper_server.py --port 8791
      
        
        
      
        
      Then open http://127.0.0.1:8791/payment-preview on the same machine.
      
        
      Demo mode needs no wallet, API key or third-party Python package. The public demos above remain archived records.
      
        
      Check an archived record locally
      python3 scripts/payment_proof.py verify site/proofs/pros-allow-live.json
      This checks the record's internal consistency. It does not authenticate the source chain data.

      About these demonstrations
      
            
      This static site selects saved JSON and videos. It does not connect to a wallet, request microphone access, query a chain or create a payment. The policy examples use a local mock; the other records contain historical read-only results.
      
            
      Public sender addresses are not proof of ownership. Alice and Bob are example contacts. Candidate transaction fields are historical, and fee and pending-nonce quotes were not pinned to the recorded block.
      
            
      The installed-Skill record shows local execution, not a hosted Pharos chat. Voice-event fixtures do not establish microphone input, speech recognition or speaker verification.
      
            
      Local P1 scope
      
            
      Batch support covers Pacific Mainnet PROS, USDC and WPROS with ordinary externally owned accounts. Rows are simulated separately at a common block; an export is not an atomic transaction and remains subject to wallet-side review.
      
            
      Cancelling does not refund an issued draft's allowance. Reservations survive restarts; allowance ages out with the rolling window, while reserved nonces are not automatically released.
      
            
      Audit hashes detect inconsistent changes, not source authenticity. Detecting a replaced or shortened history requires a trusted tip stored separately. Keep local reports and payment data private.
