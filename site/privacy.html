About this site

Privacy

This page describes the public, static Voice Action demonstration site. Running the source code locally is a separate workflow.

Browsing the demonstrations

The site loads its scripts, styles, videos, captions and recorded JSON from the same host. Its application code uses no analytics, advertising trackers, cookies or browser storage. There is no account or signup form.

Opening a page, selecting a record or playing a video sends ordinary web requests to the hosting provider. The provider may process request metadata such as IP addresses and access logs under its own policies.

Wallets and audio

The public site does not connect a wallet or request microphone access. Instructions entered in the browser sandbox are evaluated locally using example data; they are not uploaded or stored. Video narration is recorded media. Displayed addresses and amounts belong to the published example records.

Copying and downloads

The Copy command button writes the displayed local start command to your clipboard only when you select it. It does not read your clipboard. Downloads are the published files shown in the evidence library.

Working locally

The local workspace stores payment reviews, drafts and audit records on your machine. Those records can include addresses, amounts and memos. Keep them private and inspect exports before sharing them.

If you configure read-only RPC or Chain MCP access locally, those services receive the public addresses and request parameters needed for their queries. Do not enter private keys or seed phrases.

If you enable the optional local microphone, PCM audio is limited to 20 seconds and processed by a configured offline model. Temporary audio is removed after processing. A cancelled result is not imported into a payment. Voice is not speaker authentication.
